# Stock Portfolio Tracker
A simple Python program that calculates total investment value based on user input and hardcoded stock prices.

## Description
Enter stock symbols and quantities. The program uses a dictionary to look up prices, calculates the value for each stock, and shows the total investment. You can also save the result to a .txt file.
